# Proyecto Integrador — Unidad 4

## Graficación con p5.js — Iluminación y Sombreado 3D

Proyecto desarrollado utilizando p5.js y WEBGL.

## Características

- Objetos 3D
- Iluminación dinámica
- Materiales y sombreado
- Interacción con mouse y teclado
- Animaciones automáticas

## Tecnologías utilizadas

- JavaScript
- p5.js
- WEBGL

## Controles

- Mouse: mover cámara
- Tecla R: cambiar iluminación
- Tecla P: pausar movimiento
