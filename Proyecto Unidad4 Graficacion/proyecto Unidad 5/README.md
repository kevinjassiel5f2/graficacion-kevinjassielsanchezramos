# Proyecto Integrador Unidad 5

## Descripción

Proyecto desarrollado en p5.js y WEBGL para la materia de Graficación.

La escena incluye:

- Animación 3D
- Tweening
- Interpolación
- Trails
- Objetos múltiples
- Cámara interactiva
- Efectos visuales

## Herramientas utilizadas

- JavaScript
- p5.js
- WEBGL
